# Bento Grid Layout

A responsive Bento Grid Social Media Dashboard built using HTML5 and CSS Grid.



---

## 🚀 Features

- Responsive CSS Grid Layout
- Mobile-first workflow
- Modern Bento-style UI
- Fully responsive design
- Reusable card components
- Clean typography using Google Fonts

---

## 🛠️ Built With

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Google Fonts (DM Sans)
